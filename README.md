# curso-labpol-2025
Minicurso LabPol-UFSCar: "IA aplicada a textos legislativos (Text as Data)." Material que acompanha o curso do LabPol. Objetivo: coletar dados da API da Câmara dos Deputados, organizar o corpus e aplicar técnicas simples de PLN(classificação, TF-IDF, contagens e gráficos) para perguntas em Ciência Política.
